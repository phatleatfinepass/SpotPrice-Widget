FINLAND ELECTRICITY RATES — FIRST LAUNCH

This app is distributed directly by the SpotPriceWidget project. It is
ad-hoc signed to protect the integrity of the host app and widget extension,
but it is not registered with or notarized by Apple.

INSTALL

1. Drag “Finland Electricity Rates” to the Applications folder.
2. Try to open the app.
3. If macOS blocks it, open System Settings → Privacy & Security.
4. In the Security section, choose Open Anyway, then confirm Open.

Only approve an app you downloaded from the official project release page:
https://github.com/phatleatfinepass/SpotPrice-Widget/releases

The project never asks you to disable Gatekeeper or remove quarantine.

MANAGE

Use Software Update in the app to check the official GitHub release, verify
its project signature, and install the newer app transactionally. The previous
version is restored if the update cannot launch. Use Danger Zone only when
you intend to reset rebuildable app data or move the app to the Trash.
Uninstall asks for confirmation, then a narrowly scoped embedded service moves
only the currently running app to the Trash and closes it. No file picker or
manual deletion step is required.
